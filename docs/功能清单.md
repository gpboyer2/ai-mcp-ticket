# ai-mcp-ticket 功能清单

本文件列**产品功能与交互需求**（人看网页那一侧）。接口形状、字段、错误码、纯文本格式、状态约束等硬规范见 [`docs/CONTRACT.md`](./CONTRACT.md)，以它为对齐依据。

---

## 一、看板与导航

- 单页三栏：左工作区目录 / 中看板 / 右详情，**永不跳转**，三栏联动，无整页刷新
- 左栏：工作区列表（标题 + 各状态工单数小计），可折叠成图标条（localStorage 记忆）；窄屏（<1100px）收成抽屉（汉堡按钮唤出）
- 中栏：五列看板（打开/处理中/重新打开/已完成/已取消），顶部搜索 / 状态筛选 / 新建；拖拽换列与列内排序
- 右栏：点卡片原地显示详情（完整内容、评论时间线、评论增删改），中栏不消失；可关闭（回两栏）、可拖宽；窄屏浮层覆盖中栏
- URL 用 `history.pushState` 变化（可分享、可贴给 AI），不真实跳转；`popstate` 还原三栏

## 二、工单编辑

- **只有一个内容框**：工单没有标题/正文之分，整张单就是一个 `content` 字段。弹窗里是一个大 textarea，默认约 8 行、可拉高（`resize: vertical`），随便写
- 看板卡片显示 `content` 的第一行作预览（去行首 `#`/`-`/`*`/空白，截 80 字），这只是预览，不是独立字段
- 快速新建：看板顶部输入框，回车即建

## 三、评论

- 详情页评论时间线，支持增 / 删 / 改

## 四、依赖（blocked_by）

- 可搜索多选下拉：输入即过滤当前工作区工单（按 `ref` 与内容预览模糊，最多 20 条），每条显示 `{ref} {预览} 状态`；↑↓ 移动、回车选中、Esc 关闭；支持多选（逗号分隔存），已选显示可删 chip

## 五、状态流转（交互侧）

- 拖拽换列目标状态非法 → 卡片弹回原位 + 顶部 toast 说明原因（不静默回滚）
- 详情页状态选择器只列**当前状态可去**的选项（其它置灰或隐藏），从源头避免误操作
- 写操作后纯文本返回的状态提醒（见 CONTRACT 5.5.2）应被看到并据此推进状态

## 六、主题与离线

- 零 CDN、零外链，原生 HTML/CSS/JS，断网可用
- 深 / 浅色可切（localStorage，默认跟随系统），中文界面

## 七、Agents 视角

- 展示当前状态对应的纯文本 URL，一键复制，方便贴给 Agent
- 写操作默认以 `role=user, id=user` 发出（头部 `X-Actor-Role: user`）

## 八、图片

- 网页端可粘贴图片上传（接口见 CONTRACT 3.5）

## 九、验收级功能

- 建工单 → user 加评论 → AI 身份加评论（带 model）→ 改状态 → 拖拽换列 `position` 变化 → 删除，全流程无 500
- 网页能真拖拽换列、能增删改评论
